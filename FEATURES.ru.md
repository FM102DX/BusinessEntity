# Текущие фичи

Текущее приложение - это система на ASP.NET Core / Blazor Server, в которой есть:

- пространства как верхний рабочий контекст;
- папки, документы и рич-документы как бизнес-сущности;
- возможность хранить бесконечные тексты в рич-документах (ограничено только ресурсами вашей БД);
- возможность заливать картинки, видео, аудио и встраивать их в страницы;
- аутентификация через Authentik;
- администрирование пользователей, ролей, групп и прав доступа на уровне пространства;
- deployment assets для Docker Compose;
