# Backup/restore policies

В этом каталоге лежат политики, относящиеся к backup и restore пространств.

- `space-backup-policy-entity-folder-layout.md` - формат опубликованного backup пространства и правила incremental backup.
- `space-backup-restore-policy.md` - восстановление backup пространства через импорт в новое пространство.

Архитектурная фиксация: `Space` не является отдельной БД. Все пространства текущей установки/tenant живут в одной БД; физическая изоляция в отдельной БД может появиться позже только на уровне `Tenant` и должна описываться отдельной tenant-политикой.
